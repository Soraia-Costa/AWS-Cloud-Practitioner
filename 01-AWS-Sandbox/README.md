# 01 - AWS Sandbox

## Sobre o laboratório

Laboratório introdutório da formação Escola da Nuvem, com o objetivo de conhecer o ambiente AWS Sandbox e explorar o Console de Gerenciamento da AWS.

## Objetivos

- Conhecer o ambiente de laboratório AWS Sandbox.
- Acessar o AWS Management Console.
- Identificar os serviços disponíveis no ambiente.
- Conhecer as orientações básicas de acesso a instâncias EC2 por SSH.

## Serviços AWS disponíveis para exploração

- Amazon EC2
- Amazon S3
- AWS IAM
- Amazon CloudWatch
- AWS Lambda
- Amazon RDS
- Amazon VPC
- Amazon DynamoDB
- Amazon CloudFront
- Amazon Athena

## Aprendizados

Primeiro contato com o ambiente de exploração da AWS, conhecendo a estrutura do laboratório, os serviços disponíveis e suas possibilidades de utilização.

## Ferramentas utilizadas

- AWS Sandbox
- AWS Management Console
