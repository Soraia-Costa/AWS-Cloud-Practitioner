# 🚀 AWS Cloud Practitioner | Escola da Nuvem

Repositório dedicado aos meus estudos e atividades práticas desenvolvidas durante a formação em **Cloud Computing da Escola da Nuvem**, com foco nos serviços da Amazon Web Services (AWS) e na preparação para a certificação **AWS Certified Cloud Practitioner (CLF-C02)**.

## 🎯 Objetivo

Documentar minha evolução no aprendizado de computação em nuvem, reunindo laboratórios, configurações realizadas, experiências práticas e os principais conhecimentos adquiridos durante a formação.

## ☁️ Projetos e laboratórios

### 🔹 01 – AWS Sandbox

Primeiro contato com o ambiente AWS Sandbox, explorando o Console de Gerenciamento e conhecendo os serviços e recursos disponíveis na plataforma.

### 🔹 02 – Introdução ao Amazon EC2

Criação e configuração de uma instância EC2 utilizando Amazon Linux 2023. Configuração de Security Group, utilização de User Data para instalação do servidor web Apache, monitoramento da instância e teste de acesso pelo navegador.

### 🔹 03 – Criação de VPC e Servidor Web na AWS

Criação e configuração de uma Virtual Private Cloud (VPC), com sub-redes públicas e privadas, tabelas de rotas e grupos de segurança. Implantação de uma instância EC2 com servidor web Apache, utilizando script User Data.

## 🛠️ Tecnologias e serviços

- Amazon Web Services (AWS)
- AWS Management Console
- Amazon EC2
- Amazon VPC
- Security Groups
- Amazon Linux
- Apache HTTP Server
- Cloud Computing

## 📚 Sobre este repositório

Este repositório representa parte da minha jornada de aprendizado em Cloud Computing, reunindo atividades práticas e documentações que contribuem para o desenvolvimento dos meus conhecimentos em infraestrutura e serviços da nuvem.
